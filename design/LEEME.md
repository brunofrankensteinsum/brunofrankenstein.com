# Paquete de traspaso: diseño C1 «Cianotipo»

```
LEEME.md                 ← esto
PROMPT-CLAUDE-CODE.md    ← primer mensaje para pegar en Claude Code
HANDOFF.md               ← especificación completa (interacciones, animaciones, íconos, stack, plan)
design/
  tokens.css             ← colores, tipografía, espaciado, movimiento
  pantallas/             ← 6 pantallas de escritorio de referencia (.dc.html)
  iconos/                ← 20 íconos SVG + _vista-previa.html
  assets/                ← AGREGAR: retrato.jpg (no viene incluido)
```

**Uso:**
1. Descomprimí el paquete en la raíz de tu repo (o en una carpeta nueva, que va a ser el repo).
2. Copiá tu retrato a `design/assets/retrato.jpg`.
3. Abrí Claude Code en esa carpeta y pegá el contenido de `PROMPT-CLAUDE-CODE.md`.
4. Respondé las preguntas abiertas (§12 de HANDOFF.md) cuando te las haga.
